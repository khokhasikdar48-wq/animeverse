# AnimeVerse scaffold

This branch contains the initial scaffold for the AnimeVerse project.

- Frontend: frontend/ (Vite + React + TypeScript + Tailwind)
- Backend: backend/ (Express + TypeScript + Prisma)
- Infra: infra/docker-compose.yml for Postgres

Run instructions and config are in README.md. This is an initial scaffold — APIs and UI pages are placeholders and will be implemented iteratively.
