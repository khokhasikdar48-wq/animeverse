# AnimeVerse

AnimeVerse is a modern, responsive anime streaming web application scaffold (demo) for legally-owned or licensed anime/content. It contains a React + TypeScript frontend, Tailwind CSS for styling, and a Node.js + TypeScript backend API. The repository will include demo data (fictional titles) and an admin dashboard for managing titles and episodes.

Important legal note
- This project must only stream content you own or have permission to stream, or public-domain / licensed media. Do NOT include pirated sources, scraping from unofficial sites, or copyrighted content without permission.

Tech stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, TypeScript, Express
- Database: PostgreSQL (recommended) with migration and seed scripts
- Auth: JWT (bcrypt for password hashing)

Getting started (work in progress)
- A scaffold branch will be created with frontend and backend directories containing the initial project structure.

Branching
- scaffold/animeverse-app: main development branch for the app scaffold.

If you need different defaults (SQLite instead of Postgres, or prefer self-hosted uploads), reply with your preferences and I will adjust.
